# Shaimaa Nasser — Web Developer Portfolio

A responsive personal portfolio in a white + sky-blue visual style.

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No build step or npm installation is required.

## Included
- Responsive design
- Animated sections and scroll reveal
- Mobile navigation
- Services section
- Live project links
- GitHub, LinkedIn, email and phone links
- Uploaded profile photo in `assets/profile.jpg`
